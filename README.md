# 🎬 Film-Finder

A responsive web app to search for and explore movie details (ratings, synopsis, cast & crew) powered by a React + Vite frontend and an Express.js backend.

Live Demo - https://film-finderrr.netlify.app

## 🛠️ Tech Stack

- **Frontend**: React 18, Vite, Chakra UI  
- **Backend**: Node.js, Express.js  
- **API**: TMDb (The Movie Database) REST API  
- **Deployment**: Netlify (frontend) + Render (backend)
